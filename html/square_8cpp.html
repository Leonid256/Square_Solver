Функция, запрашивающая дальнейшие действия у пользователя

Функция дает пользователю выбор дальнейших действий(решение уравнений, остановка программы, открытие статистики, открытие раздела тестирования функции решения уравнений). Функция проверяет ввод, и в случае неверного ввода печатает это

Note
Функция не позволяет дважды подряд открывать раздел статистики
Parameters
[in,out]ptr_flag_statУказатель на флаг возможности открытия раздела статистики(дважды подряд открытие невозможно)
[out]ptr_flag_exitУказатель на флаг закрытия программы(для отсутствия запроса пользователя в разделе статистики)
[in,out]ptr_count_bad_enterУказатель на счетчик неверных вводов в программе
Returns
"GO" в случае выбора пользователем продолжения решения уравнений
"STOP" в случае выбора пользователем остановки программы
"STAT" в случае выбора пользователем открытия статистики
"TEST" в случае выбора пользователем открытия раздела тестирования
"CONTINUE" в случае неверного ввода

◆ main()

int main ( void )

Основная функция main.

Основная функция в программе. Вызываются функции вывода названия программы и кошечки. Далее вызывается функция запроса пользователя о дальнейших действиях. Returns
0 в случае успешного завершения
